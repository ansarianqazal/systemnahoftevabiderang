# پروژه سیستم‌های نهفته و بلادرنگ
## سیستم کنترل ماشین لباسشویی هوشمند

### ۱. معرفی پروژه
در این پروژه، رفتار یک ماشین لباسشویی هوشمند با استفاده از ماشین‌های حالت متناهی، ماشین‌های حالت توسعه‌یافته و ترکیب ماشین‌های حالت مدل‌سازی می‌شود.

این سیستم وظیفه مدیریت مراحل شست‌وشو، کنترل شیرهای ورودی آب، پمپ تخلیه، قفل ایمنی درب، سنجش وزن لباس‌ها و کنترل موتور شست‌وشو و دور تند را بر عهده دارد.

### ۲. اهداف پروژه
- مدل‌سازی ماشین لباسشویی به‌عنوان یک سیستم گسسته
- تعریف حالت‌ها، ورودی‌ها، خروجی‌ها و انتقال‌های سیستم
- استفاده از متغیرهای حالت، شرط‌های نگهبان، اکشن‌ها و تایمرها
- تفکیک منطق عادی شست‌وشو از منطق ایمنی
- مدل‌سازی واکنش سیستم در شرایط خطا

### ۳. ورودی‌های سیستم
- دکمه شروع و توقف
- وضعیت بسته‌بودن درب
- وضعیت قفل درب
- مقدار وزن لباس‌ها
- سطح آب مخزن
- پایان زمان شست‌وشو و آبکشی
- وضعیت تخلیه آب
- تشخیص سرریز آب
- تشخیص عدم تعادل بار

### ۴. خروجی‌های سیستم
- فرمان قفل درب
- فرمان شیر ورودی آب
- فرمان پمپ تخلیه
- فرمان موتور شست‌وشو
- فرمان موتور دور تند
- هشدار خطا
- اعلام پایان چرخه شست‌وشو

### ۵. ترتیب کلی چرخه شست‌وشو
آماده‌به‌کار ← بررسی وزن لباس‌ها ← قفل درب ← ورود آب ← شست‌وشو ← تخلیه آب ← آبکشی ← تخلیه نهایی ← دور تند ← پایان

### ۶. ساختار فایل‌های پروژه
- `hw-01-fsm.md`: مدل ماشین حالت ساده
- `hw-02-extended-fsm.md`: مدل ماشین حالت توسعه‌یافته
- `hw-03-composition.md`: ترکیب ماشین حالت عملیاتی و ماشین حالت ایمنی

### ۷. فرضیات مدل
این پروژه یک مدل آموزشی است و مشخصات یک ماشین لباسشویی تجاری خاص را پیاده‌سازی نمی‌کند. مقادیر زمانی، ظرفیت مجاز و آستانه‌های حسگر باید در یک پیاده‌سازی واقعی براساس مشخصات دستگاه تعیین شوند.
